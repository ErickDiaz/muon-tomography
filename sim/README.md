```

├── steering/           Parametric CORSIKA templates (one per volcano)
│   ├── fuego_template.inp       — Fuego (3,763 m basalt, primary target)
│   ├── acatenango_template.inp  — Acatenango (3,976 m andesite, calibration)

                         `cp runs_plan.example.yaml runs_plan.yaml`
```

## How runs are produced

Each invocation of `make corsika-run VOLCAN=<v> DETECTOR_POS=<p> NSHOW=<n>`:

1. Calls `scripts/_next_runnr.py` to assign a fresh `RUNNR` (sequential, derived from
   `runs.csv` — never collides across volcanoes).
2. Renders `<v>_template.inp` → `<v>_run.inp` substituting `@NSHOW@`, `@RUNNR@`, and the
   three seeds.
3. Executes CORSIKA inside the `thesis-corsika` container.
4. Appends a row to `runs.csv` recording the host, duration, atmospheric model, magnetic
   field, paths to `DATXXXXXX`, and status.

The output file is named `DATXXXXXX` where `XXXXXX` is the six-digit zero-padded `RUNNR`.

## Reading the output

```python
import corsika_panama as cp
import numpy as np

with cp.reader("sim/output/DAT001101") as f:
    for event in f:
        muons = event.particles[np.isin(event.particles.particle_id, [5, 6])]
        # particle_id: 5 = µ+, 6 = µ-
        # available columns: x, y, px, py, pz, t, particle_id, weight
        print(f"Event {event.header.event_number}: {len(muons)} muons")
```

The `analysis/corsika.py` module wraps this with a `CorsikaRun(output_dir, run_number=NNNN)`
class that also parses the `.lst` log (for metadata: atmospheric depth, observation level,
magnetic field, etc.). Used by all the notebooks.

## Notes

- DAT files and `.lst` logs are gitignored (`sim/output/`). The manifest `runs.csv` and the
  steering templates are versioned — they fully describe what was simulated.
- Change `RUNNR` and seeds for every independent run to avoid statistical correlations. The
  `make corsika-run` target handles this automatically.
